# Reports on the World Risk Poll 2021 (wave 2)

The 2021 poll: fieldwork in 2021, 125,911 respondents in 121 countries and areas. Its findings were published in four themed core reports (2022–2023) and four short Focus On reports (2023).

Data: [`WRP_2021/`](../../WRP_2021/). Each folder below reproduces one report in Python and R; see [`reports/README.md`](../README.md) for how to run them and the conventions they share.
