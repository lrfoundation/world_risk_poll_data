# Reports on the World Risk Poll 2019 (wave 1)

The 2019 poll: fieldwork in 2019, 154,195 respondents in 142 countries and areas. Its findings were published in one full report.

Data: [`WRP_2019/`](../../WRP_2019/). Each folder below reproduces one report in Python and R; see [`reports/README.md`](../README.md) for how to run them and the conventions they share.
